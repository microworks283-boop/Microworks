# Play Store release checklist

1. Open `android` in Android Studio.
2. Replace the default app icon with branded adaptive icons.
3. Add a production privacy-policy URL.
4. Connect the request form to your secure backend/API instead of localStorage.
5. Add authentication and order/payment flows.
6. Configure release signing in Android Studio.
7. Build **Android App Bundle (.aab)** for Google Play.
8. Create Play Store listing assets: 512x512 icon, feature graphic, screenshots, short/full descriptions.
9. Complete Google Play Data Safety and content declarations accurately.
10. Test on multiple Android screen sizes and offline/poor-network conditions.
